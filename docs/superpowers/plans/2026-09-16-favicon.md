# Site Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the provided tea-cup illustration as the site favicon via a local multi-size ICO that overrides the theme asset.

**Architecture:** Pillow (temporary install) converts the source PNG into `source/images/favicon.ico`; Hexo's site source overrides the theme's same-named asset, and Reimu's head already emits the `rel="shortcut icon"` link through `favicon_tag`. Tests lock the ICO structure and the override.

**Tech Stack:** Hexo 8, Reimu 1.12.5 (pinned), Node test runner, Playwright, Python 3.13 + Pillow (build-time only, temporary).

## Global Constraints

- Do not edit `node_modules/` or theme sources; the change is an asset plus config plus tests.
- The repository must not gain a Python runtime dependency; Pillow lives in a temporary directory.
- Do not add npm dependencies.
- Keep the GitHub Pages project root `/jingtine-agent-site/` in every internal link.
- Unit tests read `public/`, so always run `npm run check` before `npm run test:unit`.
- Validation order: `npm run check` → `npm run test:unit` → `npm run test:e2e`; full gate is `npm test`.
- Commit messages use conventional prefixes (see `git log`).

- [ ] **Step 1: Write the failing asset unit test**

Append to `tests/unit/assets.test.mjs`:

```js
test('ships a local multi-size favicon', async () => {
  const favicon = await readFile('source/images/favicon.ico');
  assert.equal(favicon.readUInt16LE(0), 0, 'reserved field');
  assert.equal(favicon.readUInt16LE(2), 1, 'icon type');
  assert.ok(favicon.readUInt16LE(4) >= 3, 'multiple sizes embedded');
  assert.ok(favicon.length < 100_000, `favicon is ${favicon.length} bytes`);
});
```

- [ ] **Step 2: Write the failing generated-site unit test**

Append to `tests/unit/generated-site.test.mjs`:

```js
test('serves the site favicon from the project root', async () => {
  const home = await readFile('public/index.html', 'utf8');
  assert.match(home, /<link rel="shortcut icon" href="\/jingtine-agent-site\/images\/favicon\.ico">/);
  const source = await readFile('source/images/favicon.ico');
  const published = await readFile('public/images/favicon.ico');
  assert.deepEqual(published, source, 'the site favicon overrides the theme asset');
});
```
