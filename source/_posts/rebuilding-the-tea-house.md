> 重构是九月中旬做完的，这篇算补记。

## 旧的站

旧站是手写的。HTML、CSS、JavaScript 一堆，数据靠 Python 脚本生成。最开始只想要个地方放文章，后来陆续加上了 Wiki、RSS 阅读器、论文库、知识助手、状态页、评论和留言簿。

每个都是当时想做的。问题出在后来：我打开仓库的次数越来越少——改一个样式得在十几个 HTML 文件里搜同一段 class，加一篇文章要先决定它属于哪套结构。写作的兴致，常常耗在这些事上。

有天晚上我数了数里面有多少东西，第二天决定重写。

## 换成 Hexo 和 Reimu

选 Hexo 是因为它够老，主题和文档都全。主题挑了 Reimu：响应式、深色模式、本地搜索、RSS 都是现成的。

依赖用 npm 锁死版本，构建交给 GitHub Actions，推 `main` 就自动发布。页面我不再手写了。

## 删东西

比迁移更麻烦的是删。Wiki、阅读器、论文库、助手、状态页、评论、留言簿，一个个删过去。

说实话有点舍不得，阅读器和论文库当时写了好几天。但它们半年没打开过了。最后留下的就是文章、项目、关于、友链，加上归档、分类、标签和订阅源。

九篇文章从旧格式转成 Markdown，front matter 从 TOML 换成 YAML，链接也重排成了 `/posts/:title/`。

## 摆弄的细节

基础搭好之后，审美上的活儿反而花时间：

- 侧栏从右边挪到左边，顺手删掉分类和标签两张卡片，只留最新文章；
- 标签页原来是主题给的裸链接，又小又平，后来照着 Butterfly 的样子改成彩色胶囊——颜色按标签名固定，大小按文章数分档，顺序每次构建随机；
- 首页标题下加了句轮播的茶诗，第一句是「山中何事？松花酿酒，春水煎茶。」；
- 横幅和图标都换成了茶的主题；
- 点击页面空白处会散出一小簇绿色粒子；
- 侧栏放了台播放器，十二首歌，最近在循环《一见如故》。

## 几个坑

**标签页“坏”过一次。** 有天打开自己的标签页，发现字和底色完全错开了，像没加载样式。查了一晚上：浏览器把新 HTML 和十天前的旧 CSS 拼在了一起——GitHub Pages 的缓存加上 Service Worker，谁都不肯松手。后来给自定义样式和脚本加了内容指纹，URL 后面挂一段哈希，才算根治。

**图标名字撞了。** 按常规把图标放成 `source/images/favicon.ico`，构建出来还是主题自带的那张。Hexo 里同一个路径，主题的文件优先，站点源反而排后面。换了个名字才行。

**“mp3”其实是 mp4。** 第一首歌的文件头是 `ftyp`，AAC 装在 MP4 容器里，只是扩展名写着 .mp3。用 ffmpeg 重转成真 MP3 才算完，后面十一首全是这个毛病。

**播放器被削了一角。** 文章页在「目录/导航」两个侧栏间切换时，播放器会矮掉一截。原因是 Reimu 的侧栏容器是 flex 列布局，内容变高时播放器被压扁，而它自己 `overflow: hidden`，就把内容裁了。加一句 `flex-shrink: 0` 了事。

## 测试

每次推送前会跑 48 个单元测试和 36 个浏览器用例。上面这些坑，大部分只要有一条断言就不会再犯。

所有动画也做了「减弱动态效果」的适配：系统打开这个选项，茶诗不打字、粒子不飞，页面该有的都还在。
